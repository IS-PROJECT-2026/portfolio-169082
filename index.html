01 / about

I build systems that hold up under real conditions. Most of my work this year sits at the intersection of machine learning and the infrastructure that has to run it reliably, from fraud detection pipelines to sensor networks that cannot afford to go quiet.

I am completing a BSc in Informatics and Computer Science at Strathmore University's School of Computing and Engineering Sciences, with coursework spanning distributed systems, machine learning, computer simulation and modelling, embedded systems and IoT, and multimedia applications. My capstone project applies unsupervised anomaly detection to sales agent fraud on a live platform, built in partnership with an industry client rather than as a classroom exercise.

02 / running processes

SalesMesh Fraud Detection

Capstone project built with Webmasters Kenya. Uses unsupervised anomaly detection, Isolation Forest and Local Outlier Factor, to flag fraudulent sales agent behaviour on the SalesMesh platform.

  • Python
  • Scikit-learn
  • Anomaly Detection
  • System Design

Vermiculture Watch

ESP32-based monitoring system for worm-bed conditions, built for a client through an Embedded Systems and IoT course. Reads temperature and moisture in real time and flags conditions that drift outside safe range.

  • ESP32
  • C++
  • Sensors
  • IoT
