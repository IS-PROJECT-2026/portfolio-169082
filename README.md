# Zakiya — Personal Portfolio

A personal portfolio site built as a small, functional system rather than a
static page: it documents current work in machine learning and embedded
systems through a lightweight "process monitor" layout.

## Live Deployment

https://IS-PROJECT-2026.github.io/portfolio-<your-admission-number>/

## Technologies Used

- HTML5
- CSS3 (custom properties, responsive layout, no framework)
- Vanilla JavaScript (IntersectionObserver for scroll reveal and active nav state)
- GitHub Pages for deployment

## Sections

- **About** — background and current focus
- **Projects** — current work shown as running processes with status indicators
- **Stack** — languages, tools, and areas of focus
- **Contact** — ways to get in touch
